# Jula Core

Jula Core (`github.com/alibkaba/jula-core`) contains the shared data structures and cryptographic libraries used by the Jula Continuous Compliance pipeline.

## Structure

*   **`pkg/types`**: Contains core struct models for Findings, Evidence, and Manifest files.

*   **`pkg/crypto`**: Contains ECDSA signature signing and verification methods for Manifests and Provenance sidecars.
