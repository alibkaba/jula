# CC2: Communication and Information

Relates to how the organization communicates internal control responsibilities and provides information necessary to support the internal control system.

## Status: 🔵 Partial

Jula automates the verification of system configuration and audit logging (see [cc7_system_operations.md](cc7_system_operations.md)). However, the following manual evidence is required:

1. **User Communication**: Documentation of how users are notified of system changes or security incidents.
2. **External Communication**: Procedures for communicating with external stakeholders regarding system issues.
